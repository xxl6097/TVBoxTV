# 华为应用市场 · 审核备注（提审时粘贴）

> 用途：AGC「版本信息 → 提交审核」时，把下面内容粘贴到「审核备注 / 测试说明」输入框。
> 全选复制即可，无需改动。

---

本应用是一款纯原生 ArkTS 实现的鸿蒙大屏影音播放器，**不含任何影视内容**，
所有片源均由用户自行订阅或手动导入，本应用不提供、不存储、不分发内容。

**首启流程（审核员先看这里）**

安装后首次启动先弹出隐私政策面板（可点「不同意并退出」），点「同意并继续」
后进入三步使用引导，随后进入首页。全程无需注册账号、无需登录，所有功能立即可用。

**无需账号**

本应用无账号体系，无测试账号，安装后直接使用。

**最快验证路径（推荐）**

首页点「直连」→ 粘贴任意一个 m3u8 / mp4 地址 → 点播放，即可直接播出画面。
这一步不需要任何配置，最能证明核心播放能力。

**完整功能验证路径**

1. 设置页 → 点「订阅」→ 粘贴订阅链接
   `https://s3a.abber.cn:88/public/subscribe.json`
   → 点播站源与直播源会一并导入；
2. 返回直播页即可看到按分组列出的频道，点任意频道即播；
3. 返回首页「点播」可浏览分类、搜索、收藏、查看详情与剧集。
   点播功能需在设置页导入 TVBox 格式配置地址，或通过上述订阅导入后使用。

**隐私与权限**

- 仅申请 INTERNET（访问用户自填源并播放）与 GET_NETWORK_INFO（扫码录入读取局域网 IP）两项权限；
- 无任何敏感权限、无第三方 SDK、无广告、无数据统计、无内购；
- 所有配置、收藏、历史仅保存在本机，卸载即清除。
