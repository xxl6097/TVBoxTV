夜帧影视 · 隐私政策

生效日期：2026 年 11 月 2 日最后更新：2026 年 11 月 2 日

本政策适用于「夜帧影视」（HarmonyOS 应用，包名 com.hong.tv，以下称“本应用”）。本应用是一款本地运行的影视内容浏览与播放工具，不设服务器、不设账号体系。

一、我们不收集任何个人信息

本应用没有用户注册、登录、手机号、邮箱、实名认证等任何账号功能。开发者在任何服务器上都不存储你的任何数据——原因很简单：本应用没有自己的服务器。

以下信息始终只保存在你的设备本地，开发者无法读取：

本地数据用途是否上传
你填写的点播配置地址（TVBox 格式 JSON 的 URL）拉取影片列表否
你填写的直播源地址（m3u / txt）拉取直播频道否
收藏、观看历史、播放进度本地展示与续播否
画质偏好、站源启停开关记住你的选择否
搜索关键词历史本地搜索建议否

卸载本应用即清除上述全部数据。

二、本应用会访问网络，但只做这些事

本应用需要「网络访问」权限，用途仅限于：

  • 请求你自己填写的点播配置地址，读取其中的站点接口地址；
  • 请求你自己填写的直播源地址，读取频道列表；
  • 请求上述配置中列出的第三方影视站点接口，获取影片信息、剧集列表与播放地址；
  • 连接第三方视频流地址（http/https 的 m3u8、mp4 等）播放内容；
  • 在你主动点击「测速排行」时，向这些地址发送一次探测请求以判断可用性与延迟。
这些请求由你的设备直接发往对应第三方站点，不经过开发者。因此这些第三方站点可能按它们自己的隐私政策记录你的 IP 地址、请求时间等信息。本应用无法控制也无法获知第三方站点的数据处理行为。你填写的源来自何处、信任与否，由你自行判断。

三、设备权限用途说明

权限用途是否必须
ohos.permission.INTERNET访问网络，获取你配置的片源与播放视频必须，拒绝则应用无法使用
ohos.permission.GET_NETWORK_INFO读取本机局域网 IP，用于「手机扫码录入」在电视上开一个临时服务必须，拒绝则扫码录入不可用（仍可手动输入）

本应用不申请：位置、通讯录、短信、通话记录、相机、麦克风、相册 / 文件读写、设备标识符（IMEI / OAID）、剪贴板读取、应用列表读取等任何敏感权限。

四、手机扫码录入时的局域网服务

在电视端点击源地址输入框时，本应用会在电视上临时启动一个 HTTP 服务（默认端口 8788），仅用于让同一局域网内的手机扫码打开录入页面并提交地址；手机端直接在本机输入，不启动该服务。

  • 该服务不连接任何外部服务器，不上报任何数据；
  • 提交的内容直接写入本机本地存储；
  • 离开设置页后服务即停止接受写入；
  • 页面无登录、无 Cookie、无统计脚本；
  • 仅在同一 Wi-Fi 下可访问，请勿在不可信的公共网络上开启此功能。

五、本应用不包含以下内容

  • 无第三方广告 SDK；
  • 无数据统计 / 埋点 SDK（华为分析、友盟、神策等一概没有）；
  • 无推送 SDK、无社交分享 SDK；
  • 无崩溃上报 SDK（崩溃日志仅留在系统日志中，开发者不收集）。

本应用为纯 ArkTS + ArkUI 实现，未引入任何第三方闭源二进制库。

六、儿童个人信息

本应用不面向儿童单独设计，也不收集任何个人信息（含儿童个人信息）。是否允许未成年人使用、以及观看何种内容，由监护人自行管理。

七、内容来源声明

本应用不提供、不存储、不分发任何影视内容。它是一个播放器与源管理工具，内容全部来自用户自行填写的第三方接口。

开发者不对第三方内容的合法性、准确性、可用性作任何保证，也不承担由此产生的责任。请确保你使用的内容来源合法，并遵守当地法律法规。若你是权利人认为某来源侵权，请向该来源的提供方主张权利。

八、你的权利

由于开发者不持有你的任何数据，因此不存在“申请导出 / 删除个人数据”的流程。你可以在应用内随时：

  • 修改或清空源地址（设置页）；
  • 删除单条收藏 / 历史（收藏页、历史页）；
  • 清空全部本地数据（系统设置 → 应用 → 夜帧影视 → 存储 → 清除数据）。

九、政策变更

若本政策发生实质性变更，会在应用内与发布页面同步更新，并更新本文顶部日期。继续使用即表示接受更新后的政策。
