## 应用介绍（≤ 800 字）

```
夜帧影视是一款用原生 ArkTS 与 ArkUI 编写的鸿蒙大屏影视播放器，界面按电视遥控器
的交互习惯设计，全部操作都能用方向键和确定键完成。

【原生鸿蒙，轻快省心】
纯 ArkTS 实现，无内置浏览器外壳、无第三方闭源组件，安装包仅 0.5 MB 左右。
不申请定位、通讯录、短信、相机、麦克风、相册、设备标识符等任何敏感权限，
只保留联网与读取网络状态两项。

【直播：分组目录，一屏找台】
直播频道按直播源自带的分组整理成左侧目录，央视、卫视、地方、港澳台、体育、
影视、少儿等一目了然；点分组只看该类，顶部显示「共 N 台 · M 组」与当前路径。
单个频道失效时会自动切换同名备用线路，仍不通则顺延下一个台，不用反复手动点。

【点播：分类浏览，多站聚合】
填入点播配置后可按电视剧、电影、综艺、动漫等分类浏览，支持关键词搜索、
收藏与观看历史、续播记忆，多集自动连播。

【画质：按网络自动选】
多码率片源自带多档清晰度时，起播按实测网速选档，播放中网络变差会自动降档，
变好会自动升档；也可在播放界面手动锁定清晰度。单码率片源则通过调整缓冲水位
减少卡顿与花屏。

【扫码录入，告别遥控器打字】
在电视上输入几十个字符的地址是最麻烦的一步。点击设置页的源地址栏会直接弹出
二维码，用手机扫码（需与电视连同一 Wi-Fi）在手机上粘贴地址提交，电视端立即
生效；也保留手动输入入口。整个过程不经过任何第三方服务器。

【直连播放：不配源也能用】
首页「直连」，粘一个 m3u8 / mp4 地址就能播，支持 http/https 与本机文件路径；
NAS、路由器上挂的片子，或别人发来的一条流，不用为此导入整套配置。
同样支持手机扫码输入，提交后电视直接开播。

【测速排行，选最快的源】
通过订阅一键导入点播站源与多个国内直播源，点「测速排行」会实测每个源的响应
速度并抽样验证频道能否真正播放，按「可播数量 → 响应速度」排序并把最优的设为
当前源。点播站源同样支持测速排序与批量启用。

【说明】
本应用不提供、不存储、不分发任何影视内容，也不含任何广告与数据统计 SDK。
播放内容全部来自用户自行填写与管理的第三方接口，请确保你使用的内容来源合法。
应用不含账号体系，所有配置、收藏与历史仅保存在本机，卸载即清除。
```

## 主要功能（便于审核逐条对照）

0. 首次启动展示隐私政策，同意后才联网；可直接退出
1. 直播频道按源分组浏览、播放、换台、换线
2. 点播分类浏览、搜索、收藏、历史、续播
3. 多码率自适应画质与手动锁档
4. 直播源 / 点播源测速排行
5. 手机扫码录入源地址（局域网内，无云端）
6. 遥控器全键盘操作，播放控制条 8 秒自动收起
7. 设置页的直播源与站源列表默认折叠，展开/收起一键切换，首屏即可看完全部设置
8. 直连播放：不经站源，直接播放单个地址（含手机扫码输入）

## 隐私与权限说明（审核常问，逐条回答）

| 审核问题 | 回答 |
|---|---|
| 是否收集个人信息？ | 不收集。无账号、无服务器、无埋点 SDK。 |
| 为什么需要 INTERNET？ | 访问用户自行填写的源地址并播放视频流。 |
| 为什么需要 GET_NETWORK_INFO？ | 读取本机局域网 IP，用于「扫码录入」在设备上启动临时页面。 |
| 是否有第三方 SDK？ | 无。纯 ArkTS 实现，未引入任何第三方 SDK。 |
| 数据是否上传？ | 不上传。所有配置与记录仅存本机。 |
| 是否含广告？ | 无广告。 |
| 是否含内购？ | 无。 |
| 内容来源？ | 用户自行填写第三方接口，应用本身不含任何内容。 |
